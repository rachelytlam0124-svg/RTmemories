🔥 即時共享後台設定

Firebase Firestore 連線設定教學

目前運作模式：即時模擬同步 (BroadcastChannel)

貼上 Firebase Config 後可一鍵切換為真實雲端 Firestore 資料庫，支援匿名登入與多人即時同步。

📌 貼邊度？一步步設定 Firebase Firestore：

  1. 前往 Firebase Console (console.firebase.google.com) 建立專案，並開啟 Firestore Database（選擇測試模式或建立規則）。
  2. 在 Authentication 啟用 Anonymous (匿名登入)（系統會自動為每位訪客匿名登入，無需手動輸入帳密）。
  3. 在「專案設定 > 您的應用程式 (Web)」複製 firebaseConfig 物件，貼入下方輸入框後按「儲存並連線 Firestore」。
🛡️ 建議 Firestore Rules（貼去 Firebase Console > Firestore > 規則）： 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /couple_diary_shared/{docId} {
      allow read, write: if true;
    }
  }
}
